# Manual QA Test Cases

This repository contains manual Software Quality Assurance (SQA) test case specifications, test matrices, and QA documentation for web and e-commerce workflows.

## Included Files
- **Daraz QA Test Cases Master (`Daraz_QA_Test_Cases_Master.xlsx`):** Expanded manual test cases covering login/OTP, search, cart management, promo codes, payment flows, and order tracking, including test data, expected/actual results, status, severity, priority, and execution dates.

## QA Coverage Highlights
- Functional & negative scenario testing
- Boundary and input validation checks
- Status, severity, and priority tracking
- Test execution documentation
